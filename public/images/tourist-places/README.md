# Fotografías principales de atractivos turísticos de Sucre

Las imágenes de esta carpeta se usan como fotografía principal de los registros existentes de `touristPlaces.ts` y `touristPlacesAdditional.ts`. No se añadieron registros ni galerías. Las fuentes y licencias también están centralizadas en `src/data/imageCatalog.ts`.

Las descargas se obtuvieron de Wikimedia Commons el 22-10-2026 mediante `Special:FilePath` con tamaño máximo solicitado de 1600 px. Se conservan en JPEG porque el proyecto no incluye una herramienta de conversión a WebP; las miniaturas servidas por Commons ya están reducidas respecto a los originales.

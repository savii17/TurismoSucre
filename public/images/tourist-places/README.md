Imágenes verificadas de atractivos turísticos de la ciudad de Sucre.

Usa nombres como `tourist-place-{id}-main.webp` y `tourist-place-{id}-gallery-01.webp`.
Registra el alt, la fuente, la atribución y la licencia en `src/data/imageCatalog.ts`. Mientras no haya una foto verificada, se muestra el fallback turístico.

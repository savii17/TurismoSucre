Imágenes verificadas de restaurantes ubicados en Sucre.

Usa nombres como `restaurant-{id}-main.webp` y `restaurant-{id}-gallery-01.webp`.
Registra en `src/data/imageCatalog.ts` el alt descriptivo y la fuente/licencia. Mientras no haya una foto verificada, la interfaz muestra el fallback gastronómico.
